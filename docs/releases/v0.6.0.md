petit-poucet now updates itself, works with omp, and its cleanups get lighter: deletes without a read first, a reminder that no longer counts the cleanup's own fixes, and search results without the long tail.

## 🪨 What's new

**`petit-poucet update`** (#109)
Installs the latest release over the binary the install script placed, after checking its SHA-256, then runs `setup` with it so every agent gets the new skills, subagent and hooks. The update notice now says "run `petit-poucet update`". A binary installed another way (Homebrew, `cargo install`, a build under `target/`) is left alone, with a message saying how to update it.

**omp** (#126)
`petit-poucet setup` now wires omp: the MCP server in `~/.omp/agent/mcp.json`, the skills, the `memory-cleanup` subagent in `~/.omp/agent/agents/`, and a small extension. omp runs no hook commands, so the extension gives every model call your memory and sends the save reminder at the end of a turn.

**`check` finds file names that drifted from their title** (#35)
An update can change a note's title but never renames its file. `check`, and so every cleanup review, now warns when the title no longer holds most of the file name's words, and names the `memory_move` target.

## 🔧 What's fixed

- `memory_save` answers a call with missing or misnamed fields with one error listing all of them, and its description names the six required fields, for agents that don't see the schema (#117).
- `memory_delete` on a note the agent hasn't read shows the note's text instead, and the next call deletes it: one call fewer per delete in a cleanup (#118).
- `memory_search` ranks notes by how many query words they match, then by how rare those words are, drops notes matching under half the words, and matches words by their start, so `omp` no longer finds "compile" (#120).
- The cleanup reminder no longer counts the notes a cleanup itself fixed: `tidy-memory` marks the cleanup done once its fixes are applied (#123).

## ⬆️ Upgrading from 0.5

0.5 has no `update` command yet: run the install script once more, then `setup`:

```sh
curl -fsSL https://raw.githubusercontent.com/areguig/petit-poucet/main/install.sh | sh   # macOS, Linux
irm https://raw.githubusercontent.com/areguig/petit-poucet/main/install.ps1 | iex       # Windows, PowerShell
petit-poucet setup
```

From then on, `petit-poucet update` does both. Your vault and notes don't change; the next cleanup review may list notes whose file name drifted from their title.

## 🧪 Under the hood

- A CI job installs petit-poucet into the real omp on Linux, macOS and Windows and runs a session against a mock model.
- The Antigravity CLI job follows Antigravity 1.4, whose `call_mcp_tool` takes fewer fields.
- `update` is tested end to end on every OS against releases served from a local folder, including a replacement while an MCP server started from the binary still runs.
