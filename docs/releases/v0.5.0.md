OpenCode joins the agents petit-poucet works with, and near-duplicate checks stop matching notes on filler words, in any language.

## 🪨 What's new

**OpenCode** (#10)
`petit-poucet setup` now wires OpenCode 2: the MCP server in `~/.config/opencode/opencode.json`, the skills, the `memory-cleanup` subagent, and a small plugin. OpenCode has no hooks, so the plugin gives every model call your memory and sends the save reminder at the end of a turn, as the hooks do for the other agents. OpenCode 1.x isn't supported: install OpenCode 2 with `curl -fsSL https://opencode.ai/v2/install | bash`.

## 🔧 What's fixed

- Near-duplicates no longer match notes on words like "the", "for", "les" or "pour": each note's language is detected and its filler words are left out, so two short unrelated notes aren't flagged, and real duplicates in any language still are (#105).

## ⬆️ Upgrading from 0.4

Run the install script again, then `setup`:

```sh
curl -fsSL https://raw.githubusercontent.com/areguig/petit-poucet/main/install.sh | sh   # macOS, Linux
irm https://raw.githubusercontent.com/areguig/petit-poucet/main/install.ps1 | iex       # Windows, PowerShell
petit-poucet setup
```

Your vault and notes don't change. `setup` wires OpenCode if you have it.

## 🧪 Under the hood

- A CI job installs petit-poucet into the real OpenCode on Linux, macOS and Windows and runs a session against a mock model: the memory, the tools, the skills, the save reminder and a cleanup review all reach the model.
