A maintenance release: petit-poucet keeps what it doesn't own in your agents' files, keeps your notes and their links whole when you move them, and pages long reviews without losing a line.

## 🔧 What's fixed

**Your agents' files**
- `setup` keeps the permissions of an agent's configuration file, such as a private `~/.claude.json`, and gives its backup the same ones (#169).
- `setup` and uninstall keep the other hooks that share a group with petit-poucet's (#184).
- Uninstall removes only the skill files petit-poucet installed: files you added to a skill folder stay (#185).

**Notes and projects**
- Moving a note rewrites its links to itself, so `check` no longer finds them broken (#177).
- A move into an empty topic name, such as `Topics//fact`, is refused and changes nothing (#176).
- Moving or deleting a note added outside petit-poucet and not yet committed is committed, and petit-poucet's commits leave the rest of your staged and untracked work alone (#172).
- A save from a checkout whose folder starts with a dot, such as `.dotfiles`, is refused instead of creating a project the vault can't see; pass `scope` to save into an existing project (#178).
- A remote on a non-default port, such as `ssh://git@host:2222/team/app.git`, keeps its port, so it no longer matches the same path on another port (#182). If a repo on such a port no longer finds its project, [the reference](https://github.com/areguig/petit-poucet/blob/main/docs/reference.md) says how to update its `_project.md`.
- A session no longer replaces a project remote that another session recorded after it started (#180).

**Review, usage and reminders**
- A review page stays within its size, even for a very long summary: the line goes on over the next pages (#179).
- A Syncthing conflict copy of a machine's usage file is no longer counted as another machine (#181).
- Tags are checked for secrets on save and by `check`, like the rest of a note (#183).
- Stop counters live in your own `~/.cache/petit-poucet/stops`, so another user of a shared temp folder can't silence your save reminders; a counter that can't be written is reported on stderr (#171).

**Install**
- Windows self-update retries a transient sharing violation before replacement for up to ten seconds. It stops retrying if the installed executable changes or its identity can't be read (#209).
- When the install folder isn't on your PATH, the printed `setup` command is quoted, so it runs as printed from a folder with spaces in its name (#186).

## ⬆️ Upgrading from 0.7.0

```sh
petit-poucet update
```

Your notes don't change. Restart your agents.

## 🧪 Under the hood

- The release workflow gives write permission only to the job that publishes the release; CI and the Syncthing workflow read contents only (#173).
- Agent tests clear an inherited `PETIT_POUCET_VAULT` before using their throwaway home (#170).
- Agent tests fail fast when the mock model dies or never prints its port (#174).
- The agent review check fails when the first review page reaches the model cut short or saved to a file (#187).
- The Syncthing-absence test no longer depends on where git is installed on the host (#175).
