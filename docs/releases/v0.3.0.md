One memory for every agent you switch between: petit-poucet now installs as a single binary and sets itself up in each agent you use.

## 🪨 What's new

**Install once, set up every agent** (#42, #11)
An install script puts the `petit-poucet` binary on your PATH, checksum verified. `petit-poucet setup` then wires every agent it finds, `setup --check` says what's missing, and `setup --uninstall` takes it all out again. Config files keep everything else, with a `.petit-poucet.bak` copy of what changed.

**Codex** (#9, #65)
`setup` adds the MCP server to `~/.codex/config.toml` and the session-start and stop hooks to `~/.codex/hooks.json`. Trust them once in Codex with `/hooks`. A resumed session keeps its memory without loading it twice.

**Cursor** (#40)
`setup` adds the MCP server to `~/.cursor/mcp.json` and the hooks to `~/.cursor/hooks.json`.

**Antigravity CLI** (#60)
`setup` adds the MCP server and hooks to `~/.gemini/config/`. Memory reaches the model before each of its calls. Antigravity replaces Gemini CLI, which no longer serves personal Google accounts.

**Claude Code and Copilot without the plugin** (#68)
`setup` now wires Claude Code and Copilot (CLI, VS Code, IntelliJ, the Copilot app) directly, like every other agent, with no launcher script in between. It removes the 0.2 plugin first, so its hooks don't run twice.

**No more plugins** (#70)
petit-poucet is one binary and `setup` wires every agent, so the Claude Code and Copilot plugins are gone. Coming from 0.2: install the binary, then run `petit-poucet setup`. It removes the plugin and sets the agent up directly. Until then, the installed plugin keeps working with its 0.2.2 binary.

**Skills everywhere** (#62)
For every agent, `setup` also installs the `memory`, `migrate-memory` and `tidy-memory` skills and the `memory-cleanup` subagent that `tidy-memory` hands the review to.

## 🔧 What's fixed

- `init` and `setup` work on a machine with no git identity; the first commit waits until you set one (#49).
- `setup` finds a Copilot plugin installed from a local folder (#54).
- `setup` reads an empty agent config file as no settings yet (#60).
- `setup --uninstall` no longer writes an empty `"hooks": null` into a settings file that had no hooks (#68).

## 🧪 Under the hood

- CI runs every test on Windows too (#12).
- Each agent's CI job installs petit-poucet into the agent's real CLI and runs a session against a mock model, checking the memory, tools, skills and save reminder that reach it (#51, #64).
