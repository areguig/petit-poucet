One memory for every agent you switch between. petit-poucet is now a single binary that sets itself up in Claude Code, GitHub Copilot, Codex, Cursor and Antigravity CLI, on macOS, Linux and Windows: what you teach one agent, the others know.

## 🪨 What's new

**Install once, set up every agent** (#42, #11)
An install script puts the `petit-poucet` binary on your PATH, checksum verified. `petit-poucet setup` then wires every agent it finds: the MCP server, the session-start and stop hooks, the skills and the `memory-cleanup` subagent. `setup --check` says what's missing, `setup --uninstall` takes it all out again (your vault stays), and `--agent` limits either to one agent. Config files keep everything else, with a `.petit-poucet.bak` copy of what changed.

**Codex** (#9)
`setup` adds the MCP server to `~/.codex/config.toml` and the hooks to `~/.codex/hooks.json`. Trust them once in Codex with `/hooks`. A resumed session keeps its memory without loading it twice (#65).

**Cursor** (#40)
`setup` adds the MCP server to `~/.cursor/mcp.json` and the hooks to `~/.cursor/hooks.json`.

**Antigravity CLI** (#60)
`setup` adds the MCP server and hooks to `~/.gemini/config/`, and memory reaches the model before each of its calls. Antigravity CLI replaces Gemini CLI, which no longer serves personal Google accounts.

**Claude Code and Copilot, without the plugin** (#68, #70)
`setup` wires Claude Code and Copilot (CLI, VS Code, IntelliJ, the Copilot app) directly, like every other agent, with no launcher in between. The plugins are gone: `setup` removes the 0.2 plugin with the agent's own command first, so its hooks don't run twice.

**Windows** (#12)
Release binaries for Windows on x64 and ARM, and a PowerShell installer. `setup` writes hooks every agent can run on Windows, from any install folder, spaces included.

**Skills everywhere** (#62)
Every agent gets the `memory`, `migrate-memory` and `tidy-memory` skills, and the `memory-cleanup` subagent that `tidy-memory` hands the review to, in that agent's own format.

**Update notice** (#69)
Once a day, session start checks GitHub for a new release in the background, without delaying the session, and tells you when one is out. `petit-poucet check` reports the latest release too. `PETIT_POUCET_NO_UPDATE_CHECK=1` turns the check off.

## 🔧 What's fixed

- `init` and `setup` work on a machine with no git identity; the first commit waits until you set one (#49).
- `setup` finds a Copilot plugin installed from a local folder (#54).
- `setup` reads an empty agent config file as no settings yet (#60).
- `setup --uninstall` no longer writes an empty `"hooks": null` into a settings file that had no hooks (#68).

## ⬆️ Upgrading from 0.2

Your vault, notes and config don't change. Install the binary, then run `setup`:

```sh
curl -fsSL https://raw.githubusercontent.com/areguig/petit-poucet/main/install.sh | sh   # macOS, Linux
irm https://raw.githubusercontent.com/areguig/petit-poucet/main/install.ps1 | iex       # Windows, PowerShell
petit-poucet setup
```

`setup` removes the Claude Code and Copilot plugins and wires those agents directly; until you run it, the installed plugin keeps working with its 0.2.2 binary. Restart your agents afterwards, and in Codex trust the new hooks once with `/hooks`.

## 🧪 Under the hood

- Every test runs on Linux, macOS and Windows (#12).
- One CI job per agent and OS installs petit-poucet into the agent's real CLI and runs a session against a mock model, checking the memory, tools, skills and save reminder that reach it, and that the background update check completes (#51, #64, #69).
